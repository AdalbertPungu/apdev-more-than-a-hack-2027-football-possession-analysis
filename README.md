# Ball Possession Recognition - More Than A Hack 2027

A temporal possession segmentation solution for the **More Than A Hack 2027** initial challenge.
Using automatic tactical tracking and Smart Tagging, the program assigns a label to every frame
of the FC Barcelona - Athletic Club match.
