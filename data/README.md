# Match data

This directory holds the tactical data obtained through the official competition channel.
It is not distributed with the public repository and must not be published or
redistributed. Place the following three files in the `tactical` subfolder.

Files used:

- `BAR-ATH_tactical_atd.xml`
- `BAR-ATH_tactical_atd.txt`
- `BAR-ATH_tactical_smart_tagging.xml`

These files are the only inputs to the generator. The contents of the `tactical` subfolder
are excluded from the repository by `.gitignore`.
